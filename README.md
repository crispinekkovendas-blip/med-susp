# Banco SUS-SP — VUNESP

Banco de questões comentadas para a Seleção Pública para Residência Médica do
SUS-SP (banca VUNESP), acesso direto: Pediatria, Medicina Preventiva e Social,
Cirurgia e Ginecologia e Obstetrícia. Todas as questões são reais, extraídas
dos cadernos oficiais, com o gabarito oficial.

| O quê | Onde |
|---|---|
| Banco na tela | https://susp.vercel.app/ |
| Caderno para imprimir | https://susp.vercel.app/caderno/ |
| Deploy | `npx vercel deploy --prod --yes` a partir de `med/susp/` (projeto `susp`) |
