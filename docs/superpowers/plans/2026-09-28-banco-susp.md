# Banco SUS-SP (VUNESP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A deployed, printable, harness-verified bank of 100 real VUNESP residency questions (25 each of Pediatria, Medicina Preventiva e Social, Cirurgia, Ginecologia e Obstetrícia), each with an official gabarito, a full commentary, a plain-language commentary and references.

**Architecture:** A fork of `med/gineco/inepam/` (static data file + screen app + printable caderno + Node harness with negative controls) where the list of areas is data (`BANCO.meta.areas`), the question text is extracted from the official cadernos by a PyMuPDF script and never typed by hand, and `banco.js` is generated by `ferramentas/montar.js` from three inputs: extracted questions, parsed gabaritos, and hand-written commentary files. The harness proves that every enunciado and alternativa is literally in the source caderno and every gabarito matches the official key.

**Tech Stack:** Plain HTML/CSS/JS (no build), Node 24 (harness, montar, controls, fake DOM), Python 3.14 + PyMuPDF 1.27 (extraction, gabarito parsing, tool tests), `pdftotext` (xpdf 4, in Git's mingw64) for gabarito/ruling PDFs, Vercel static deploy, git.

**Spec:** `docs/superpowers/specs/2026-09-28-banco-susp-design.md` (read it first; this plan argues from it and records where facts found during planning changed it — see "Facts that changed since the spec" below).

## Facts that changed since the spec (verified 2026-09-28)

- **VUNESP ran only the SUS-SP 2026 edition.** SUS-SP 2025 (applied 14/12/2024) and 2022 were Quadrix. So SUS-SP gives 20 per area, and Cirurgia lost 3 to annulments: the 2026 acesso direto annulled questions are **4, 21, 23, 36** (from the edital de análise de recursos of 20/01/2026; outcomes in that ruling are only `Indeferido` and `ANULADA`, so no letter changed).
- **The user chose to fill the gap with other VUNESP residency exams.** UNESP Botucatu 2026, FAMEMA 2026 and Einstein 2025 use **four** alternatives and are excluded. **HRPP 2026** (Hospital Regional de Presidente Prudente, VUNESP, applied 30/11/2025, 100 questions, five alternatives A–E, gabarito preliminar downloaded and verified) is the secondary source: 5 per area, 8 for Cirurgia. Its caderno PDF was not found on a public mirror during planning; Task 13 lists the retrieval attempts and the fallback.
- **Vunesp's own site is closed to scripts and to non-candidates** (403 to curl/WebFetch; "Provas e Gabaritos" requires candidate login). Sources are the mirrors listed in Task 2.
- **The 2026 caderno is two-column with some full-width questions**, question numbers are `NN.` + TAB, alternatives `(A)` + TAB, and the PDF mixes soft hyphens (U+00AD) with hard hyphens at line breaks. The PyMuPDF block approach in Task 4 parsed all 100 questions cleanly in a prototype.
- **Expected counts per area are a harness constant** `ESPERADO = { ped, prev, cir, go }` (not one `POR_AREA`), so a shortfall in one area (if HRPP cannot be sourced) is explicit rather than hidden.

## Global Constraints

- Everything written into the project (UI text, comments, README, commit messages, tool output) is **pt-BR**; replies to the user are English.
- No framework, no build step: `app.js` and `caderno/caderno.js` must run in the browser and in the harness's fake DOM (`document.createElement`, `append`, `replaceWith`, `querySelector(All)` by tag/class/id only, `localStorage`, `setTimeout`/`setInterval`, `confirm`).
- **`banco.js` is generated** by `node ferramentas/montar.js` and never edited by hand. Content edits go to `ferramentas/entrada/<area>.js`; text of questions comes only from `ferramentas/cadernos/<fonte>-questoes.json`.
- Every question: `alternativas.length === 5`; `correta` in `0..4`; `comentario` ≥ 600 chars, opens with `Questão N (ROTULO)`, has exactly one `Gabarito <strong>X</strong>`, mentions `<strong>A</strong>`…`<strong>E</strong>`, closes with a paragraph containing `O que a banca testa`; `simples` ≥ 200 chars, says `a letra <strong>X</strong>`, average ≤ 14 words per sentence, none > 26; `tema` 8–70 chars; `referencias` 1–3 entries of 10–120 chars; HTML tags only `p strong em ul ol li table thead tbody tr th td sub sup br`.
- Areas in `meta.areas` order: `ped, prev, cir, go`. Ids `<area>01…`. Inside an area: fontes in `meta.fontes` order, then `numero` ascending.
- Student-facing label: `${fonte.rotulo} · Questão NN` (e.g. `SUS-SP 2026 · Questão 55`, `HRPP 2026 · Questão 12`). `rotulo` is `NOME ANO`; `edicao` equals the year in `rotulo`.
- localStorage keys are prefixed `susp:` (`susp:respostas`, `susp:simulado`, `susp:filtro`, `susp:aba`, `susp:caderno`). Never `inepam:*`.
- Scripts containing backslashes are written with the Write tool and run from a file — never through a Bash heredoc (the heredoc mangles `\`).
- Every harness check gets a negative control in `controles.js`; a control that changes nothing is an error.
- Deploy only from `med/susp/`: `npx vercel deploy --yes` (preview), `npx vercel deploy --prod --yes` (production). `.vercelignore` keeps harness, controls, tooling, docs and README off the air.
- Commit after every task; commit messages in pt-BR, ending with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

`ferramentas/baixar.js`:

```js
/* Baixa os documentos-fonte para cadernos/ (pula o que já existe) e imprime
   tamanho e md5 de cada um. Espelhos públicos, porque vunesp.com.br devolve
   403 a scripts e exige login de candidato para "Provas e Gabaritos".
   Roda: `node ferramentas/baixar.js` */
const fs = require("fs"), path = require("path"), https = require("https"), crypto = require("crypto");
const DIR = path.join(__dirname, "cadernos");
const UA = "Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/128.0";
const ARQUIVOS = [
  ["susp2026-caderno.pdf", "https://arquivos.qconcursos.com/prova/arquivo_prova/143800/vunesp-2025-ses-sp-residencia-medica-acesso-direto-prova.pdf"],
  ["susp2026-gabarito-preliminar.pdf", "https://med.estrategia.com/portal/wp-content/uploads/2025/12/SESA2504_306_20251216094031.pdf.pdf"],
  ["susp2026-recursos.pdf", "https://cdn.medblog.estrategiaeducacional.com.br/wp-content/uploads/2026/01/SESA2504_306_20260120131302.pdf.pdf"],
  ["hrpp2026-gabarito-preliminar.pdf", "https://med.estrategia.com/portal/wp-content/uploads/2025/12/HRPP2501_306_20251202163016.pdf.pdf"],
  ["hrpp2026-resultado.pdf", "https://med.estrategia.com/portal/wp-content/uploads/2026/01/HRPP2501_306_20260126122312.pdf.pdf"],
];
function baixar(url, destino, saltos = 0) {
  return new Promise((ok, falha) => {
    https.get(url, { headers: { "User-Agent": UA } }, r => {
      if ([301, 302, 303, 307, 308].includes(r.statusCode) && r.headers.location && saltos < 5) { r.resume(); return ok(baixar(new URL(r.headers.location, url).href, destino, saltos + 1)); }
      if (r.statusCode !== 200) { r.resume(); return falha(new Error(`HTTP ${r.statusCode} em ${url}`)); }
      const w = fs.createWriteStream(destino);
      r.pipe(w); w.on("finish", () => w.close(ok)); w.on("error", falha);
    }).on("error", falha);
  });
}
(async () => {
  fs.mkdirSync(DIR, { recursive: true });
  for (const [nome, url] of ARQUIVOS) {
    const p = path.join(DIR, nome);
    if (!fs.existsSync(p)) await baixar(url, p);
    const b = fs.readFileSync(p);
    if (b.slice(0, 5).toString() !== "%PDF-") { fs.unlinkSync(p); throw new Error(`${nome}: não é PDF (o espelho mudou?)`); }
    console.log(`${nome}\t${b.length} bytes\tmd5 ${crypto.createHash("md5").update(b).digest("hex")}`);
  }
})().catch(e => { console.error(e.message); process.exit(1); });
```

```python
"""Gabarito oficial em linhas "NN X" (X = A–E, ou * para anulada).

Entrada: o texto (pdftotext -layout) do edital de divulgação do gabarito, que
lista todas as provas ("001. PROVA OBJETIVA", "002. …") com pares "NN - X";
opcionalmente o texto (pdftotext -raw) do edital de análise de recursos, de
onde saem as anulações da prova pedida, e/ou uma lista manual --anuladas.

    python ferramentas/parse_gabarito.py --preliminar cadernos/susp2026-gabarito-preliminar.txt \
        --recursos cadernos/susp2026-recursos.txt --prova 001 --saida cadernos/susp2026-gabarito.txt
"""
import argparse, re, sys

def letras_da_prova(texto, prova):
    """Os pares "NN - X" do bloco da prova pedida, até o bloco seguinte."""
    blocos = re.split(r"(?m)^\s*(\d{3})\.\s*PROVA\s+OBJETIVA", texto)
    # blocos = [antes, "001", corpo, "002", corpo, ...]
    for i in range(1, len(blocos), 2):
        if blocos[i] == prova:
            corpo = blocos[i + 1]
            pares = re.findall(r"(\d{1,3})\s*-\s*([A-E])\b", corpo)
            letras = {}
            for n, x in pares:
                n = int(n)
                if n in letras:
                    break          # a numeração recomeçou: acabou a prova
                letras[n] = x
            return letras
    raise SystemExit(f"prova {prova} não encontrada no gabarito")

def anuladas_do_edital(raw, prova):
    """Questões da prova pedida marcadas ANULADA no edital de recursos.
    O -raw do SUS-SP quebra em três linhas: "001 - Prova" / "Objetiva" /
    "1 23 ANULADA" (versão 1, questão 23). Outros editais (FAMEMA) trazem
    tudo numa linha, sem versão: "001 - Prova Objetiva 36 ANULADA"."""
    anuladas = set()
    atual = None
    for linha in raw.splitlines():
        linha = linha.strip()
        m = re.match(r"^(\d{3}) - Prova Objetiva (\d+) ANULADA$", linha)
        if m:
            if m.group(1) == prova:
                anuladas.add(int(m.group(2)))
            atual = None
            continue
        m = re.match(r"^(\d{3}) - Prova(?: Objetiva)?$", linha)
        if m:
            atual = m.group(1)
            continue
        m = re.match(r"^\d+ (\d+) ANULADA$", linha)
        if m and atual == prova:
            anuladas.add(int(m.group(1)))
    return anuladas

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--preliminar", required=True)
    ap.add_argument("--recursos")
    ap.add_argument("--anuladas", default="")
    ap.add_argument("--prova", default="001")
    ap.add_argument("--saida", required=True)
    a = ap.parse_args()
    with open(a.preliminar, encoding="utf-8", errors="replace") as f:
        letras = letras_da_prova(f.read(), a.prova)
    anuladas = set(int(x) for x in a.anuladas.split(",") if x.strip())
    if a.recursos:
        with open(a.recursos, encoding="utf-8", errors="replace") as f:
            anuladas |= anuladas_do_edital(f.read(), a.prova)
    if sorted(letras) != list(range(1, len(letras) + 1)):
        raise SystemExit(f"numeração com buracos: {sorted(letras)[:10]}…")
    with open(a.saida, "w", encoding="utf-8", newline="\n") as f:
        for n in sorted(letras):
            f.write(f"{n} {'*' if n in anuladas else letras[n]}\n")
    print(f"{a.saida}: {len(letras)} questões, anuladas {sorted(anuladas) or 'nenhuma'}")

if __name__ == "__main__":
    main()
```

```python
"""Extrai as questões de um caderno VUNESP (PDF) com PyMuPDF.

Por página, os blocos de texto são ordenados assim: um bloco "largo" (mais de
60 % da largura) abre uma faixa vertical; dentro de cada faixa vêm primeiro
os blocos da coluna esquerda, depois os da direita, cada um de cima para
baixo. Isso reproduz a ordem de leitura de um caderno em duas colunas em que
algumas questões são compostas na largura toda. Blocos de imagem viram a
linha "[IMAGEM]" (a questão que a contém é marcada `imagem: true`).

Hifens de fim de linha: hífen suave (U+00AD) é sempre hifenização e some;
hífen comum junta as duas partes, salvo quando a parte esquerda é um prefixo
que leva hífen (pré, pós, recém…) ou um prefixo que leva hífen diante de h
ou de vogal igual (anti-histamínico, intra-abdominal). Toda decisão vai para
<saida>-hifens.txt, para revisão humana.

    python ferramentas/extrai_questoes.py --pdf ferramentas/cadernos/susp2026-caderno.pdf \
        --primeira-pagina 3 --rodape "SESA2504/001-AcessoDireto|Confidencial até o momento da aplicação\\." \
        --blocos "cm:1-20,cir:21-40,ped:41-60,go:61-80,prev:81-100" --saida ferramentas/cadernos/susp2026
"""
import argparse, json, re, sys

SEMPRE_HIFEN = {"pré", "pós", "pró", "recém", "ex", "vice", "bem", "mal", "não", "sem", "além", "aquém",
                "grão", "grã", "anos", "beta", "alfa", "gama", "delta", "ômega", "primeiro", "segundo"}
PREFIXOS = {"anti", "auto", "contra", "extra", "infra", "intra", "semi", "sub", "super", "ultra", "micro",
            "macro", "neo", "pan", "co", "multi", "inter", "trans", "hiper", "hipo", "mini", "sobre",
            "pseudo", "retro", "supra", "ante", "arqui", "sócio", "socio", "tele", "agro", "eletro", "geo",
            "hidro", "mega", "poli", "proto", "psico", "auto", "peri", "endo", "epi", "para"}

def juntar_hifens(texto):
    texto = texto.replace("\xad\n", "").replace("\xad", "")
    # hífen repetido na quebra ("queixa-\n-se", "Ringer-\n-lactato"): a banca
    # repete o hífen de um composto/ênclise partido — fica UM hífen, sem quebra
    texto = re.sub(r"([^\W\d_]+)-[ \t]*\n[ \t]*-([^\W\d_]+)", r"\1-\2", texto)
    # espaço perdido entre o hífen e a quebra ("proges- \nterona") vira "-\n"
    texto = re.sub(r"-[ \t]+\n", "-\n", texto)
    decisoes = []
    def f(m):
        a, b = m.group(1), m.group(2)
        al = a.lower()
        mantem = al in SEMPRE_HIFEN or (al in PREFIXOS and (b[0].lower() == "h" or b[0].lower() == al[-1] or (al == "sub" and b[0].lower() in "br")))
        saida = a + "-" + b if mantem else a + b
        decisoes.append(f"{a}-/{b} → {saida}" + (" (mantido)" if mantem else ""))
        return saida
    return re.sub(r"([^\W\d_]+)-\n\s*([^\W\d_]+)", f, texto), decisoes

def texto_ordenado(pdf, primeira_pagina):
    import fitz
    doc = fitz.open(pdf)
    linhas = []
    for pno in range(primeira_pagina - 1, doc.page_count):
        page = doc[pno]
        w = page.rect.width
        blocos = page.get_text("blocks")
        largos = sorted([b for b in blocos if b[2] - b[0] > 0.6 * w], key=lambda b: b[1])
        def faixa(b):
            return sum(1 for l in largos if l[1] <= b[1] + 1)
        def chave(b):
            if b[2] - b[0] > 0.6 * w:
                return (2 * largos.index(b), 0, round(b[1]))
            col = 0 if (b[0] + b[2]) / 2 < w / 2 else 1
            return (2 * faixa(b) - 1, col, round(b[1]))
        for b in sorted(blocos, key=chave):
            linhas.append("[IMAGEM]" if b[6] == 1 else b[4].rstrip("\n"))
    return "\n".join(linhas)

def limpar(texto, rodape):
    padrao = r"(?m)^\s*(" + rodape + r"|\d{1,2})\s*$\n?"
    return re.sub(padrao, "", texto)

def separar_questoes(texto):
    partes = re.split(r"(?m)^(\d{2,3})\.\t[ ]*", texto)
    limpa = lambda s: re.sub(r"\s+", " ", s).strip()
    questoes = []
    for i in range(1, len(partes), 2):
        numero, corpo = int(partes[i]), partes[i + 1]
        m = re.search(r"(?m)^\(A\)\t[ ]*", corpo)
        if not m:
            questoes.append({"numero": numero, "erro": "sem alternativa (A)"}); continue
        enunciado, resto = corpo[:m.start()], corpo[m.start():]
        alts = re.split(r"(?m)^\(([A-E])\)\t[ ]*", resto)
        letras, textos = alts[1::2], [limpa(t) for t in alts[2::2]]
        imagem = "[IMAGEM]" in enunciado or any("[IMAGEM]" in t for t in textos)
        enunciado = limpa(enunciado.replace("[IMAGEM]", " "))
        textos = [limpa(t.replace("[IMAGEM]", " ")) for t in textos]
        q = {"numero": numero, "enunciado": enunciado, "alternativas": textos, "imagem": imagem}
        if letras != list("ABCDE"):
            q["erro"] = f"alternativas {letras}"
        questoes.append(q)
    return questoes

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--pdf", required=True)
    ap.add_argument("--primeira-pagina", type=int, default=1)
    ap.add_argument("--rodape", default=r"Confidencial até o momento da aplicação\.")
    ap.add_argument("--blocos", required=True, help='ex.: "cm:1-20,cir:21-40,ped:41-60,go:61-80,prev:81-100"')
    ap.add_argument("--saida", required=True)
    a = ap.parse_args()
    areas = {}
    for parte in a.blocos.split(","):
        area, faixa = parte.split(":"); ini, fim = map(int, faixa.split("-"))
        for n in range(ini, fim + 1): areas[n] = area
    texto = limpar(texto_ordenado(a.pdf, a.primeira_pagina), a.rodape)
    texto, decisoes = juntar_hifens(texto)
    with open(a.saida + ".txt", "w", encoding="utf-8", newline="\n") as f: f.write(texto)
    with open(a.saida + "-hifens.txt", "w", encoding="utf-8", newline="\n") as f: f.write("\n".join(decisoes) + "\n")
    questoes = separar_questoes(texto)
    problemas = [q for q in questoes if "erro" in q]
    for q in questoes:
        q["area"] = areas.get(q["numero"], "?")
    with open(a.saida + "-questoes.json", "w", encoding="utf-8", newline="\n") as f:
        json.dump(questoes, f, ensure_ascii=False, indent=1)
    imagens = [q["numero"] for q in questoes if q.get("imagem")]
    print(f"{len(questoes)} questões; {len(problemas)} com problema {[(q['numero'], q['erro']) for q in problemas]}; com imagem: {imagens}; {len(decisoes)} hifens decididos (ver {a.saida}-hifens.txt)")
    if problemas or len(questoes) != len(areas):
        sys.exit(1)

if __name__ == "__main__":
    main()
```

```js
/* Normaliza texto para comparar o banco com o caderno: tags viram espaço,

function normalizar(s) {

    .replace(/<[^>]+>/g, " ")
```

```js
/* Escreve banco.js a partir do objeto: chaves sem aspas, strings em JSON,
   campos na ordem fixa, uma questão por bloco, um cabeçalho por área. Só o
   montar.js chama isto; banco.js nunca é editado como texto. */
const CAMPOS = ["id", "area", "tema", "fonte", "edicao", "numero", "texto", "enunciado", "alternativas", "correta", "referencias", "comentario", "simples"];
const CABECALHO = `/* ============================================================================

     · ferramentas/cadernos/<fonte>-questoes.json — enunciado e alternativas

     · ferramentas/cadernos/<fonte>-gabarito.txt — o gabarito oficial;
     · ferramentas/entrada/<area>.js — tema, referências, comentário e
       Simplificando, escritos à mão.
   Não edite este arquivo: mude a entrada e rode \`node ferramentas/montar.js\`.
   ========================================================================== */

const j = v => JSON.stringify(v);
function serializar(banco) {
  const linhas = [CABECALHO + "window.BANCO = {"];
  linhas.push("  meta: " + JSON.stringify(banco.meta, null, 2).replace(/\n/g, "\n  ") + ",");
  linhas.push("  questoes: [");
  let area = null;
  for (const q of banco.questoes) {
    if (q.area !== area) {
      area = q.area;
      const nome = (banco.meta.areas.find(a => a.id === area) || {}).nome || area;
      linhas.push("", "/* " + "=".repeat(74), "   " + nome.toUpperCase(), "   " + "=".repeat(74) + " */", "");
    }
    const partes = [];
    for (const k of CAMPOS) {
      if (q[k] === undefined) continue;
      if (k === "alternativas" || k === "referencias") partes.push("  " + k + ": [\n" + q[k].map(a => "    " + j(a) + ",").join("\n") + "\n  ]");
      else partes.push("  " + k + ": " + j(q[k]));
    }
    linhas.push("{ " + partes.join(",\n").replace(/^  /, "") + " },", "");
  }
```

```js
/* Monta banco.js: junta o texto da banca (questoes.json), o gabarito oficial
   e o que foi escrito à mão (entrada/<area>.js). Ids por área, na ordem de
   meta.areas; dentro da área, na ordem de meta.fontes e depois pelo número
   da questão na prova. Aborta em qualquer inconsistência — banco.js só
   existe se tudo bateu. Roda: `node ferramentas/montar.js` */
const fs = require("fs"), path = require("path");
const RAIZ = path.join(__dirname, "..");
const meta = require("./meta.js");
const { serializar } = require("./serializar.js");

const questoesDe = {}, gabaritoDe = {};
for (const f of meta.fontes) {
  const base = path.join(RAIZ, f.caderno.replace(/\.txt$/, ""));
  questoesDe[f.id] = Object.fromEntries(JSON.parse(fs.readFileSync(base + "-questoes.json", "utf8")).map(q => [q.numero, q]));
  gabaritoDe[f.id] = Object.fromEntries(fs.readFileSync(path.join(RAIZ, f.gabarito), "utf8").trim().split(/\r?\n/).map(l => { const [n, x] = l.trim().split(/\s+/); return [Number(n), x]; }));
}
const ordemFonte = Object.fromEntries(meta.fontes.map((f, i) => [f.id, i]));
const questoes = [];
for (const a of meta.areas) {
  const arq = path.join(__dirname, "entrada", a.id + ".js");
  const entradas = fs.existsSync(arq) ? require(arq) : [];
  entradas.sort((x, y) => (ordemFonte[x.fonte] - ordemFonte[y.fonte]) || (x.numero - y.numero));
  const vistos = new Set();
  entradas.forEach((e, i) => {
    const onde = `${a.id} ${e.fonte} #${e.numero}`;
    if (!(e.fonte in questoesDe)) throw new Error(`${onde}: fonte desconhecida`);
    const q = questoesDe[e.fonte][e.numero];
    if (!q) throw new Error(`${onde}: número não existe no caderno`);
    if (q.area !== a.id) throw new Error(`${onde}: no caderno essa questão é do bloco ${q.area}`);
    if (q.erro) throw new Error(`${onde}: a extração marcou problema (${q.erro})`);
    const g = gabaritoDe[e.fonte][e.numero];
    if (!g || g === "*") throw new Error(`${onde}: sem gabarito ou anulada (${g})`);
    if (vistos.has(e.fonte + "#" + e.numero)) throw new Error(`${onde}: repetida`);
    vistos.add(e.fonte + "#" + e.numero);
    for (const k of ["tema", "comentario", "simples"]) if (typeof e[k] !== "string" || !e[k].trim()) throw new Error(`${onde}: falta ${k}`);
    if (!Array.isArray(e.referencias) || !e.referencias.length) throw new Error(`${onde}: falta referencias`);
    const fonte = meta.fontes.find(f => f.id === e.fonte);
    const obj = { id: a.id + String(i + 1).padStart(2, "0"), area: a.id, tema: e.tema, fonte: e.fonte, edicao: fonte.edicao, numero: e.numero };
    if (e.texto) obj.texto = e.texto;
    Object.assign(obj, { enunciado: q.enunciado, alternativas: q.alternativas, correta: "ABCDE".indexOf(g), referencias: e.referencias, comentario: e.comentario, simples: e.simples });
    questoes.push(obj);
  });
}
fs.writeFileSync(path.join(RAIZ, "banco.js"), serializar({ meta, questoes }), "utf8");
console.log(`banco.js: ${questoes.length} questões (${meta.areas.map(a => `${a.id} ${questoes.filter(q => q.area === a.id).length}`).join(" · ")})`);
```

```js
/* ============================================================================
   BANCO SUS-SP — o comportamento.

   Sem framework: são cem cartões e três estados por cartão. O que a
   página faz cabe em quatro coisas:

     · filtrar por área (cada área de meta.areas) ou por edição (cada prova
       de meta.fontes que já tem questão no banco);
     · responder: um clique numa alternativa marca, corrige na hora e abre o

     · o SIMULADO: cinco questões de cada área sorteadas, na ordem da prova,
```

`ferramentas/conferir_readme.js`:

```js
/* Confere que a tabela de números do README bate com banco.js.
   A tabela tem uma linha por área ("| Pediatria | 20 | 5 | 25 |") e uma
   de total; as colunas são as fontes na ordem de meta.fontes, depois o
   total. Roda: `node ferramentas/conferir_readme.js` */
const fs = require("fs"), path = require("path"), vm = require("vm");
const RAIZ = path.join(__dirname, "..");
const ctx = vm.createContext({ window: {} });
vm.runInContext(fs.readFileSync(path.join(RAIZ, "banco.js"), "utf8"), ctx);
const B = ctx.window.BANCO, Q = B.questoes;
const readme = fs.readFileSync(path.join(RAIZ, "README.md"), "utf8");
const erros = [];
const linha = nome => {
  const m = readme.match(new RegExp("^\\| \\*?\\*?" + nome.replace(/[.*+?^${}()|[\]\\]/g, "\\$&") + "\\*?\\*? \\|([^\\n]*)$", "m"));
  return m ? m[1].split("|").map(s => s.trim().replace(/\*/g, "")).filter(Boolean).map(Number) : null;
};
for (const a of B.meta.areas) {
  const esperado = B.meta.fontes.map(f => Q.filter(q => q.area === a.id && q.fonte === f.id).length);
  esperado.push(Q.filter(q => q.area === a.id).length);
  const lido = linha(a.nome);
  if (!lido || lido.join() !== esperado.join()) erros.push(`${a.nome}: README diz ${lido ? lido.join(" / ") : "nada"}, banco tem ${esperado.join(" / ")}`);
}
const total = B.meta.fontes.map(f => Q.filter(q => q.fonte === f.id).length).concat(Q.length);
const lidoTotal = linha("Total");
if (!lidoTotal || lidoTotal.join() !== total.join()) erros.push(`Total: README diz ${lidoTotal ? lidoTotal.join(" / ") : "nada"}, banco tem ${total.join(" / ")}`);
if (!readme.includes(`${Q.length} questões`)) erros.push(`o README não diz "${Q.length} questões" em lugar nenhum`);
for (const e of erros) console.log("   ! " + e);
console.log(erros.length ? `${erros.length} diferença(s) entre README e banco.` : "README bate com o banco.");
process.exit(erros.length ? 1 : 0);
```
